COMPONENT 2: INQUIRY SYSTEM ✅
─────────────────────────────────────────────────────────────────────────────
Files:       app/api/inquiries/route.js (8.8 KB, 254 lines)
             data/inquiries.json (database)
Routes:      POST /api/inquiries
             GET /api/inquiries
             PATCH /api/inquiries/:id
Status:      ✅ Fully functional

Features:
  ✓ Submit custom tier inquiry (from /checkout?tier=custom)
  ✓ Validate email and required fields
  ✓ Store inquiry in JSON database
  ✓ Auto-reply email with demo link
  ✓ Admin can view all inquiries
  ✓ Admin can mark as responded
  ✓ Track response notes

API Endpoints:
  POST /api/inquiries
    Request:  { accountId?, companyName, contactName, email, phone?, 
                hospitalsNeeded?, notes? }
    Response: { success, inquiryId, message, demoUrl }
    
  GET /api/inquiries
    Response: { success, inquiries: [] }
    
  PATCH /api/inquiries/:id
    Request:  { inquiryId, responseNotes }
    Response: { success, inquiry }

Integration Points:
  - POST /api/checkout calls POST /api/inquiries for custom tier
  - Sends auto-reply email via Resend (if API key configured)
  - Returns demoUrl in response
  - Links inquiry to account via accountId

Database Schema:
  {
    id: string,
    accountId: string | null,
    companyName: string,
    contactName: string,
    email: string,
    phone: string | null,
    hospitalsNeeded: number | null,
    inquiryNotes: string | null,
    responded: boolean,
    responseNotes: string | null,
    createdAt: ISO8601,
    updatedAt: ISO8601
  }

Usage:
  1. Submit inquiry at: http://localhost:3000/checkout?tier=custom
  2. Check data/inquiries.json for record
  3. View in admin dashboard: http://localhost:3000/settings/inquiries

CONFIGURATION
─────────────────────────────────────────────────────────────────────────────

Environment Variables (Optional):

  RESEND_API_KEY
    - For auto-reply emails
    - Get from: https://resend.com
    - If not set: inquiries still save, emails not sent (non-blocking)

  NEXT_PUBLIC_DEMO_VIDEO_URL
    - For demo video embed
    - Example: https://www.youtube.com/embed/xxxxx
    - Default: YouTube placeholder

  NEXT_PUBLIC_APP_URL
    - For email template links
    - Example: https://yourdomain.com or http://localhost:3000
    - Default: http://localhost:3000

Setup:
  1. Create .env.local in project root
  2. Add environment variables (optional)
  3. Restart dev server
  4. Changes take effect immediately
